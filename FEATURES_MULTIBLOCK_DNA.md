# Мультиблоки и ДНК

В этой ветке добавлены сборочный ключ, сворачивание завершённых мультиблоков в цельные 3D-машины, интерфейс исключений ДНК, прогресс извлечения с лучом и метаданные источника/качества ДНК-образцов.

Полный патч применяется проверочной GitHub Actions-сборкой из `ci_payload` и упаковывается вместе с готовым JAR.
